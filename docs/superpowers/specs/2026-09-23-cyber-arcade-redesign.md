# CyberSuraksha Arcade Redesign

## Goal

Rebuild all 18 Cybersecurity, Artificial Intelligence, and Cyber Fraud lessons to match the interaction depth of the existing non-English Class 3 modules while reducing required reading.

## Experience

- Every lesson is a playable mission with four unlocked stages: **Watch**, **Try**, **Challenge**, and **Use It**.
- The first teaching beat is visual. Instructions use icons, motion, demonstrations, and one short sentence at a time.
- Every action changes the simulated world immediately. Learners move characters, sort objects, operate tools, inspect evidence, build defences, or control a safe device simulation.
- Wrong choices pause the action and demonstrate a smaller safe example before play resumes.
- Lessons retain progressive hints, keyboard operation, reduced-motion support, local progress restoration, scoring, and teacher/student completion behavior.

## Recurring Cast

- **Tara** — playful Class 3–4 explorer who learns by trying.
- **Kabir** — Class 5 gamer and maker who likes testing systems.
- **Meera** — Class 6–7 investigator who checks evidence before acting.
- **Byte** — friendly robot guide appearing in every lesson through reactions, demonstrations, and celebrations.

Characters use shared project-owned SVG/CSS artwork so their faces, colours, clothing, and expressions remain consistent across lessons.

## Distinct Simulations

### Classes 3–4

1. Pack private information into a locking backpack.
2. Play a building game while handling an unknown-player interruption.
3. Operate a home lab and observe whether tools remember, predict, or only follow a switch.
4. Train Byte on examples, then test the learned sorting rule on a conveyor.
5. Play a coin-collection arcade while closing fake reward pop-ups.
6. Use a borrowed-phone simulator and physically hand the device to a trusted adult when a risky screen appears.

### Class 5

1. Forge an account shield from passphrase and recovery pieces.
2. Moderate a live class-group simulation without escalating harm.
3. Race a chatbot answer against source cards and evidence stamps.
4. Tune a recommendation machine and observe how actions reshape the feed.
5. Direct animated money flow in a safe UPI simulator with no real PIN or financial data.
6. Sweep a giveaway scene with a clue lens and lock suspicious elements into an evidence board.

### Classes 6–7

1. Scan photo layers to reveal location and metadata clues.
2. Inspect a near-real login page using URL, certificate, and domain tools.
3. Build an AI-assisted assignment workflow separating learner thinking, AI suggestions, and verified sources.
4. Assemble a media evidence board where uncertainty remains a valid conclusion.
5. Switch communication channels to verify an urgent money request.
6. Investigate an influencer shop while protecting a limited budget.

## Quality Bar

- No lesson depends on video, audio, typed personal data, external navigation, OTP, PIN, or real payment details.
- No two lessons share the same primary game mechanic, opening, stage choreography, or completion scene.
- Controls remain at least 44 px, focus-visible, and functional with keyboard and touch.
- Motion communicates state and stops under `prefers-reduced-motion`.
- English lesson visuals and structure are not used as the reference implementation.
