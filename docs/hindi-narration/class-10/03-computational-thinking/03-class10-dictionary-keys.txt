अदिति डिसीजन lab में काल्पनिक प्रदर्शनी की बही खोलती है। विहान हर प्रदर्श को छोटी कुंजी और token गिनती देता है। screen पर कार्ड खिसक सकते हैं, लेकिन जाँच भर कुंजी और मान का संबंध जुड़ा रहना चाहिए।

Search card पर BK लिखा है। अदिति cards के screen order की जगह उसी key से जुड़ी value देखती है। यहाँ uppercase और lowercase अलग हैं। इसलिए मिलता-जुलता lowercase code उस key का match नहीं है।

विहान मौजूद प्रदर्श कुंजी पर set लगाता है। उसका पुराना मान बदलता है। बही में उस कुंजी की एक ही एंट्री रहती है; मान बदलना पुरानी दोहरी एंट्री नहीं बचाता।

खोज NX माँगती है, जिसकी एंट्री नहीं। उनका साफ़ default rule बिना जोड़े 0 लौटाता है। ऐसा जवाब चुनें जो खोज का सही रिज़ल्ट दे और बही वही रखे।

अलग set कार्ड दिए मान के साथ NX साफ़ तौर पर जोड़ता है। अब एंट्री गिनती बढ़ती है, पिछली खोज की तरह नहीं। अदिति पहले और बाद के मैप लिखती है ताकि बदलना, गायब होना और जोड़ना बाद की जाँच में अलग सबूत छोड़ें।

वे अलग कुंजियों में अभी रखे मान ही जोड़ते हैं। बदले पुराने मान फिर नहीं गिनते और गायब खोज का रिज़ल्ट अतिरिक्त एंट्री नहीं है। आखिरी सबूत में अक्षर rule, default rule और हर माना मैप बदलाव है।
