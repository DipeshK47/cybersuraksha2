message कहता है मेकर मेले की गाइड खिसक गई है। पेज स्कूल के रंग और लंबे host की शुरुआत में परिचित नाम रखता है। तारा पहला मिलता शब्द देखकर रुकने की जगह पूरा पता teacher के रेफ़रेंस से मिलाती है।

host पते का साइट पहचानने वाला हिस्सा है। जुड़े अंत या बदले शब्द दूसरी जगह बता सकते हैं। class सिर्फ़ कागज़ पर आरक्षित उदाहरण नाम लेती है; तुलना को संदिग्ध पेज खोलना या password देना नहीं पड़ता।

safe connection चुनी साइट तक जाती जानकारी बचाता है; वहाँ का हर दावा सही नहीं करता। नील पुराने स्कूल बुकमार्क से लौटकर teacher से बदलाव पूछता है। उसी message का link दोहराना अलग पुष्टि नहीं है।

host teacher के सही रेफ़रेंस से अलग है। ज्ञात स्कूल माध्यम से बदलाव नहीं बताया गया। तारा लंबे host का क्या करे? अब दिए हुए options में अपना जवाब चुनें और उसे check करें। आगे जाने से पहले feedback पढ़ें।

रुकें, पुराने स्कूल रास्ते से लौटें और बदलाव पूछें। परिचित शुरुआत और connection चिह्न नई माँग सही होना साबित नहीं करते।

अब practice lab में आपकी बारी है। यहाँ तीन हिस्से हैं। पहला, पूरा host। दूसरा, connection और भरोसा। और तीसरा, ज्ञात अलग रास्ता। हर जवाब check करें और feedback पढ़ें। ज़रूरत हो तो फिर कोशिश करें। अपना record save करें। अपने तरीके की एक limitation भी बताएँ।
