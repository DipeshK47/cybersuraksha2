नील को मेले के लिए छापने वाला क्राफ़्ट नमूना चाहिए। विज्ञापन नमूने से पहले सुधार प्रोग्राम लगाने कहता है। तारा माँग को teacher के मंज़ूर folder से मिलाती है, जहाँ काम का आसान दस्तावेज़ पहले है।

आकर्षक file नाम जितना उसका मकसद अहम है। दस्तावेज़ पढ़ना और app लगाना अलग कदम हैं। परिचित चिह्न या नाम source, अंदर की सामग्री या प्रोग्राम खुलने के बाद की access माँग साबित नहीं करता।

class बिना software लिए काल्पनिक file कार्ड मिलाती है। वे ज्ञात साधन चुनकर अचानक माँग teacher से पूछते हैं। update और install स्कूल के तरीके से हों, विज्ञापन के सामान्य पढ़ाई से पहले नया साधन लगाने के वादे से नहीं।

काम को छापने वाला दस्तावेज़ चाहिए। teacher का ज्ञात folder देता है; विज्ञापन असंबंधित सुधार install माँगता है। नील पहले कौन सा साधन ले? अब दिए हुए options में अपना जवाब चुनें और उसे check करें। आगे जाने से पहले feedback पढ़ें।

मंज़ूर दस्तावेज़ रास्ता लें और teacher को असंबंधित install माँग बताएँ। क्राफ़्ट का काम अतिरिक्त प्रोग्राम का कारण नहीं है।

अब practice lab में आपकी बारी है। यहाँ तीन हिस्से हैं। पहला, source और मकसद। दूसरा, दस्तावेज़ या app। और तीसरा, अचानक access माँग। हर जवाब check करें और feedback पढ़ें। ज़रूरत हो तो फिर कोशिश करें। अपना record save करें। अपने तरीके की एक limitation भी बताएँ।
