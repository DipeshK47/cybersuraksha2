मेकर गाइड का शुरुआती draft और teacher का मंज़ूर नया रूप है। काल्पनिक device खराबी के बाद नील को सही नाम मगर पुरानी सामग्री वाली file मिलती है। तारा पूछती है copy कहाँ बची और कौन सा रूप चाहिए।

रूप किसी चरण की सामग्री बताता है; जगह copy कहाँ है बताती है। खोए लैपटॉप के दोनों रूप अनुपलब्ध हो सकते हैं। अलग मंज़ूर backup बच सकता है, पर पूरा और सही नया रूप होना फिर भी जाँचना है।

teacher अकेले मूल पर लिखे बिना जाँच जगह copy लौटाते हैं। class खोलकर मंज़ूर चित्र और पन्ने मिलाती है। सिर्फ़ file नाम या प्रोग्रेस पट्टी काफ़ी नहीं; लौटे काम को उपयोगी और बताई ज़रूरत जैसा होना है।

team को मंज़ूर नया रूप चाहिए। एक copy खुलकर पुराना draft देती है; दूसरी teacher के मंज़ूर पन्नों से मिलती है। कौन सी वापस मिली file बताई ज़रूरत पूरी करती है? अब दिए हुए options में अपना जवाब चुनें और उसे check करें। आगे जाने से पहले feedback पढ़ें।

मंज़ूर नए रूप से मिलती जाँची copy लें और recovery record रखें। पुराना draft खुलना अभी का काम लौटना नहीं है।

अब practice lab में आपकी बारी है। यहाँ तीन हिस्से हैं। पहला, रूप और जगह। दूसरा, अलग backup। और तीसरा, जाँची वापसी। हर जवाब check करें और feedback पढ़ें। ज़रूरत हो तो फिर कोशिश करें। अपना record save करें। अपने तरीके की एक limitation भी बताएँ।
