Generated with the built-in ImageGen tool on 25 October 2026. These original fictional school scenes extend the warm, cinematic illustration style of the earlier CyberSuraksha lessons. Device screens are illustrative; the actual evidence and interactive controls remain in HTML.

Final assets live in `public/cyber-missions/class-11/`, optimised as 1400px-wide WebP images. No learner data, narration, scoring or progress identities were changed.

## Shared prompt

Use case: illustration-story. Create one polished landscape illustration for an Indian Class 11 cybersecurity lesson. Cinematic stylised 3D editorial story illustration matching an existing educational game: tactile materials, believable school environment, expressive older-teen characters, soft painterly detail, warm afternoon light contrasted with deep teal shadows, cream, forest teal and amber palette. Detailed environmental storytelling with a clear focal subject, not a diagram, not a UI screenshot, not flat vector art. Full-bleed landscape 16:9 composition, important subject within the middle 80% so it works on phones. No writing, letters, logos, watermarks, floating padlocks, shields, binary digits, holograms or decorative cyber symbols. Device screens may show simple unlabeled shapes and rows, never readable text.
